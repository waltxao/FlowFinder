# Superpowers 工程方法论

## 一句话定位
把 coding agent 变成守纪律的工程师：先想清、写计划、强制测试、系统收尾。

## 能力介绍（粘贴到平台表单）
Agent 软件工程方法论框架。需求一来不急着写码，先头脑风暴出规格文档，再拆成「2-5 分钟一个」的可执行实施计划（精确到文件路径与验证命令），强制红绿 TDD，用子代理驱动开发并做两段式评审，系统化调试，最后收尾合并。理念：测试驱动、系统化优于临场、降低复杂度、证据优于声称。适用于功能开发、重构、修 bug、写实施计划、做代码评审。
