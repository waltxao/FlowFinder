## 2. 设置项行为细则

| 设置 | 键 | 默认 | 生效点 |
|---|---|---|---|
| 启动时打开 | `startup_location`（已接线） | 0 = 上次位置 | `FFStartupPath` + 新增活动面板持久化；0 走会话，1 主目录，2 桌面 |
| 启动时检查更新 | `check_update_on_startup` | 开 | 启动后异步检查（24h 节流）；关于页手动按钮不受开关限制 |
| 默认视图 | `default_view_mode`（已接线） | 列表 | 新窗口初始视图 |
| 移动前确认 | `confirm_file_operations`（语义收窄） | 关 | 拖拽移动 / ⌘⇧X / 剪切粘贴 / 菜单移动前弹 sheet |
| 默认操作行为 | `default_file_behavior`（改字符串） | 跟随访达 | `FileListView.isMoveOperation`；⌘ 反转 |
| 文件夹优先排序 | `folder_first_sort` | 开 | `PaneState.sortEntries`；关闭时纯字段排序 |
| 刷新保持选中 | `keep_selection_position` | 关 | 同目录 refresh 后恢复仍存在的选中项 |
| SMB 默认域 | `smb_default_domain` | 空 | `ConnectServerDialog` 新增「域」字段并预填；URL `smb://domain;user@host:port/share` |
| SMB 自动重连 | `smb_auto_reconnect` | 关 | 启动时重连已保存连接；SMBBridge 断线重连开关 |

## 3. 状态与文案

- 移动确认 sheet：标题「确认移动」，正文「将 N 个项目移动到「目录」？可用 ⌘Z 撤销。」按钮「取消 / 移动」。
- 更新提示：「发现新版本 <版本戳>」+「当前 <本机版本>」+「前往下载 / 稍后」；离线失败不提示。
- 状态栏 SMB：`正在重连「卷名」（2/3）`、`「卷名」已重新连接`、`「卷名」重连失败` +「重试」；5 秒后自动回落项目计数。
- 关于页新增「检查更新」按钮；检查中禁用并显示「检查中…」。
