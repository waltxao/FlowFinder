## 0. 为什么需要这份文件

项目此前有 20 份按日期堆叠的设计稿，每份都是「这一轮改什么」，没有任何一份定义「什么算改对了」。后果是视觉基准在 18 天内换了 6 次：

```
07-20 完整重构 → 07-22 访达风格 → 07-27 访达重设计
→ 07-28 克隆访达 → 07-29 全面重设计 → 08-04 液态玻璃
```

其中 08-04 的记录是「液态玻璃不符合预期、没有浮动在操作区上方的玻璃效果」——那时要的是更多玻璃，而访达没有液态玻璃。这与 07-28 的「完全克隆访达」本身互斥。两条都被写进了「硬约束」，于是每一轮都可以合法地推翻上一轮。

本文件的作用：**把「对标访达」和「产品自主」分开，各自给出可判定的规格**。分开之后，「不像访达」不再能用来否定一个产品自主决策。

## 1. 两类基准

| 类别 | 含义 | 判定方式 |
|---|---|---|
| **对标访达** | 材质、选中态、字号、行高、侧栏结构、列头、分组、面包屑、详情栏内容项 | 必须与访达视觉一致，可测量 |
| **产品自主** | 双行工具栏 72pt、双操作区、详情栏浮层高度、设备浮层、标签药丸 | 不要求像访达，按本文件规格；**不得以「不像访达」为由返工** |

判定标记：

- ✅ 符合，不动
- ⚠️ 有偏差，需调整
- ❌ 设计冲突，待裁定
- 🔧 实现与设计不符（缺陷）

### 5.1 标准位置专属图标（B-06）

系统 `NSWorkspace.icon(forFile:)` 对标准目录返回的是「蓝色文件夹 + 淡色内嵌符号」，在 20pt 下内嵌符号几乎不可见，几个位置看起来都是蓝文件夹。故对标准位置改用合成图标。

| 项 | 值 |
|---|---|
| 画布 | 20×20pt，矢量绘制（`NSImage(size:flipped:drawingHandler:)`，随屏幕缩放自动清晰） |
| 容器 | 超椭圆圆角矩形，radius 4pt，填语义色，四周内缩 1pt |
| 符号 | SF Symbol 白色（`paletteColors: [.white]` 而非模板色），最长边 = 容器的 56%，居中 |
| 缓存 | `NSCache`，key = 标准化路径 |

标准位置映射（路径先展开 `~`、去尾斜杠、解析符号链接，再做全等比对，不做前缀匹配）：

| 位置 | 路径 | 符号 | 色值 |
|---|---|---|---|
| 桌面 | `~/Desktop` | `display` | `#4A90D9` |
| 文稿 | `~/Documents` | `doc.text` | `#5B7FB8` |
| 下载 | `~/Downloads` | `arrow.down` | `#3E9BC4` |
| 应用程序 | `/Applications` | `square.grid.2x2.fill` | `#7E6BC4` |
| 图片 | `~/Pictures` | `photo` | `#E0A33A` |
| 影片 | `~/Movies` | `film` | `#D4683C` |
| 音乐 | `~/Music` | `music.note` | `#C2564E` |
| 主目录 | `~` | `house` | `#4A90D9` |

未命中映射 → 回退 `NSWorkspace.icon(forFile:)`（自定义收藏保持真实图标，不破坏 B-05）。

> 取舍：B-05 的「彩色真实图标」是为否决「蓝色单色模板 SF Symbols」而定的。本条用语义色 + 白色符号的**合成**图标，不是单色模板，两者不冲突。标准位置需要的是「一眼可区分」，系统文件夹图标在 20pt 下做不到。

### 5.2 标签行式规格（B-10）

| 项 | 值 |
|---|---|
| 行高 | 24pt，行间距 2pt（原药丸态 22 + 6） |
| 色点 | 8×8 圆形，`tag.color` 实色，leading 6pt，垂直居中 |
| 名称 | 13pt 常规，`labelColor`，色点右侧 6pt，尾部截断 |
| 计数 | 11pt，`secondaryLabelColor`，trailing 6pt 右对齐；0 / 未知时隐藏 |
| 常态底 | 透明 |
| 悬停底 | `labelColor` 6%，radius 5pt |
| 筛选态底 | `controlAccentColor` 15%，名称 semibold |
| 点击区 | 整行（不再是药丸范围） |

计数语义与来源：

- 语义为「**当前活动面板所显示目录内**带该标签的项目数」，不是全库统计。访达的标签侧栏也不显示计数，此处是增值信息。
- 来源：目录变化后后台并发读 xattr（复用 `TagBridge` 缓存），限制 5000 文件、并发 8、防抖 300ms、代次校验。超上限或读失败时返回空表 → 不显示数字，而不是显示错误的 0。
- key 为标签名：原生标签（`_kMDItemUserTags`）每次读取生成随机 id，不能作稳定 key。

|---|---|---|---|
| 1 | 字体令牌收敛（只换令牌不改数值）+ 间距令牌化 | 无 | 截图逐像素无差异 |

## 17. 冻结规则

批次 1–3 完成后，本文件的令牌表生效。此后：

1. 任何视觉改动必须指向表中某一条，且只改那一条
