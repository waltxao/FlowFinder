# FlowFinder 产品定义

> **版本：** 1.0
> **日期：** 2026-10-17
> **性质：** 本文件只回答四件事：是什么、给谁、核心场景、不做什么。规格见 `docs/DESIGN-SPEC.md`，验收见 `docs/ACCEPTANCE.md`。
> **写法约束：** 每条都标注依据。没有依据的推断不写进本文件。

---

## 1. 一句话定义

**FlowFinder 是 macOS 上的原生双栏文件管理器，让需要同时看两个目录的人不必在窗口之间来回切换。**

| 依据 | 内容 |
|---|---|
| 用户确认 | 2026-10-17：价值主张「三者并重、需排序」，其中双栏为差异化核心 |
| 用户原话 | 「V0.8.0 是一个可以面向普通用户的测试版」（2026-10-21 起产品版本统一为 **0.8.0 Beta**；2026-10-22 起构建号规则为 `A.B.C-yymmddxx`，当前显示 `0.8.0-26102201 Beta`，见 `CHANGELOG.md` 与 `SPEC-2026-10-21-UI-ROUND2.md` §5.5） |
| 用户多次强调 | 双栏布局必须保留，是产品核心 |
| 历史起点 | 2026-07-18 首份设计稿：「完整复刻原版 FlowFinder 双面板布局」——双栏是最初的产品身份，早于「像访达」的视觉追求 |

---

## 2. 目标用户

| 层级 | 用户 | 核心场景 |
|---|---|---|
| **主要** | 普通 Mac 用户中，有整理与搬运需求的人 | 把下载目录的文件分拣到各项目文件夹；备份；清理重复文件 |
| 次要 | 需要批量处理文件的半专业用户 | 批量改名、打标签、两目录间对拷 |

**不假设**用户是开发者。所有界面文案、错误提示、引导都以非技术用户能读懂为准。

---

## 3. 三条价值线及其关系

三条都要，但不并列——有先后，冲突时按此顺序取舍：

| 顺序 | 价值线 | 内容 | 说明 |
|---|---|---|---|
| 1 | **双栏搬运** | 两目录同时看、跨面板复制/移动、拖拽跨栏 | **差异化核心**。没有它，产品没有存在理由 |
| 2 | **整理能力** | 批量重命名、重复文件扫描、标签、规则打标签 | 增值项。是「比访达多做的事」，但不是切换的理由 |
| 3 | **专业效率** | 大目录性能、SMB、全键盘、任务中心 | 场景延展。服务于第 1、2 条，不单独作为卖点 |

**取舍规则**：当三者冲突（工具栏空间、设置项数量、开发时间）时，优先保 1，其次 2，3 可延后。

---

## 4. 与访达的关系

**视觉贴近访达是手段，不是目标。**

| 维度 | 定位 | 依据 |
|---|---|---|
| 视觉一致性 | 降低普通用户的学习成本，不是追求像素级复刻 | 2026-10-17 裁定：视觉按「结构对齐 + 令牌表」验收 |
| 材质、选中态、字号、行高、侧栏结构、列头、分组、面包屑 | **对标访达**，可测量 | 见 `DESIGN-SPEC.md` §1 |
| 双行工具栏、双操作区、详情栏浮层高度、设备浮层、标签药丸 | **产品自主**，不要求像访达 | 同上 |
| 交互语义（拖拽复制/移动判定、快捷键、选中行为） | 与访达一致 | v0.6.6 / v0.7.0 |

> 历史教训：2026-07-28 把「完全克隆访达」写成硬约束，2026-08-04 又按「要更多液态玻璃」重做——两条本身互斥，导致视觉基准 18 天内换了 6 次。本文件把「对标」与「自主」分开，避免同一句话被两边同时引用。

## 5. 核心旅程

发布前必须全部通过，判定标准见 `ACCEPTANCE.md` §3。

| # | 旅程 | 一句话 |
|---|---|---|
| J1 | 首次打开 → 看到自己的文件 | 装上就能用，不出现空窗口 |
| J2 | 双栏搬文件 | 左栏选、拖到右栏、到位——这是产品的存在理由 |
| J3 | 全键盘找并打开文件 | ⌘F → ↑↓ → Enter |
| J4 | 误删恢复 | 删除 → ⌘Z 回原位 |
| J5 | 遇到问题知道怎么办 | 无权限 / 只读 / 断线，给中文说明与下一步 |

## 6. 明确不做

| 不做 | 理由 |
|---|---|
| 不接管系统默认文件管理器、不注册「打开方式」 | 避免与访达争夺系统角色 |
| 不做云盘同步、版本控制、代码编辑 | 不在问题域内 |
| 不做 iOS / iPadOS 协同 | 仅 macOS 桌面 |
| 首个测试版不做多语言，仅简体中文 | 用户约定（版本号 0.8.0 Beta） |
| 不上 App Store | 无 Developer ID，走 ad-hoc 分发 |
| 不做插件系统 | 收益不明确，成本高 |

---

## 7. 明确不追求

| 不追求 | 理由 |
|---|---|
| 像素级复刻访达 | 无法判定通过与否，是 12 轮返工的直接原因 |
| 「AI」作为卖点 | 打标实为扩展名规则引擎， overstated 违反诚实性底线 |
| 功能数量领先同类 | 三条价值线的取舍规则优先于数量 |
| 视觉上的「更精致」 | 视觉冻结后只做定点修复，不做整体重设计 |

---

## 8. 术语

| 词 | 含义 |
|---|---|
| 双栏 / 双操作区 | 窗口内左右两个独立的文件浏览区，各自有工具栏、列表、详情栏 |
| 跨面板操作 | 把一个面板选中的文件复制/移动到另一个面板的当前目录 |
| 对标访达 | 必须与访达视觉一致、可测量的项目 |
| 产品自主 | 按本产品规格执行、不要求像访达的项目 |
| 视觉冻结 | 令牌表生效后，视觉改动必须指向具体条目，禁止整体重设计 |
