## 2. 目标视觉系统

### 2.1 圆角

| 层 | 半径 | 曲线 |
|---|---|---|
| 窗口 | 12 | `.continuous` |
| 操作面板 | 12 | `.continuous` |
| 详情栏 | 8 | `.continuous` |
| 卡片/浮层 | 8 | `.continuous` |
| 控件 | 6 | `.continuous`（按钮/输入） |

规则：外层半径 ≥ 内层半径；不再出现 16/10/6 的反层级；所有层使用同一曲线族。

### 2.2 间距

4 / 8 / 12 / 16 / 24；窗口内容边距 16；面板内边距 8；详情栏内边距 8–10；工具/搜索/查重卡片内边距 12。

### 2.3 详情栏

- 收起 54pt；展开最小 120pt、最大为面板高度 45%（上限 260pt），超出滚动。
- 左侧预览图标：应用级滑块 48–96，默认 64；右侧信息自适应。
- 信息网格：可用宽度 ≥480 两列；<480 单列；路径单行中间省略 + tooltip；标签最多两行。
- 无选择保持旧版收起摘要；多选聚合数量/总大小，不加载媒体。

### 2.4 工具浮层

- 标题只写“工具”，副标题显示当前路径 + 选择摘要（不写左/右面板）。
- 分组：整理（查重、批量）、任务、设置/关于。
- 行高 32、图标列 16、禁用项显示原因；上下文可在工具行内提示“作用于当前选择”。

### 2.5 搜索

- 保留独立窗口；顶部 28pt 搜索框 + 范围 chip。
- 空态居中：图标、标题“搜索这台 Mac”、说明、主按钮“构建内容索引”、次入口“只搜索文件名”。
- 左侧筛选合并为一张卡片；结果表保持现有列。

### 2.6 查重

- 四段：条件卡片、结果区（空态/分组）、右侧预览卡片、底部动作栏。
- 空态：图标 + “还没有扫描结果” + 主按钮“开始扫描”。
- 底部：组数/文件数、可释放空间、选择重复项、取消选择、确认删除（危险色，未选禁用）。

### 2.7 辅助窗口

- 设置/批量重命名统一 12/8/6、16pt 内边距、系统字体字号；不重排批量结构。
- 冲突弹窗按钮顺序：跳过 / 保留两者 / 替换…；跳过为默认；替换危险色。
- 标签关闭视觉 20、命中 24；侧栏最小 180。

## 3. 状态与可访问性

| 状态 | 要求 |
|---|---|
| 空 | 图标 + 标题 + 一句说明 + 明确下一步；不显示空白表格 |
| 加载 | 保留现有 spinner；超过 300ms 显示；不改变布局 |
| 错误 | 居中错误图标/标题/原因/“重试”；按钮 ≥28pt |
| 禁用 | 降低对比度并给原因；颜色不是唯一信号 |
| 多选 | 聚合数量/大小，不读媒体 |
| 无选择 | 详情栏保持 54pt 收起摘要 |
| 深色/高对比 | 文字 ≥4.5:1；分隔线可见；选中态可辨 |
| Reduce Motion | 关闭弹跳/长动画；详情展开直接到位 |
| 键盘 | Tab 顺序=视觉顺序；标签关闭可聚焦；工具行可键盘执行 |

## 5. 验收

- 1400×900 与 1060×700、浅/深色：窗口/面板/详情/控件圆角符合 12/12/8/6；无内层大于外层。
- 详情展开图标滑块生效（48–96），信息随宽度一/两列，路径省略；高度上限 45%。
- 工具浮层分组、无左右面板标题、上下文提示可见。
- 搜索空态主 CTA 居中；查重四段空态/动作条正确。
- 冲突弹窗默认跳过、替换危险色；标签关闭命中 24；侧栏最小 180。
- XCTest/自检全绿；对比度/焦点/VoiceOver 走查记录。

## 6. 显式假设

1. 批量重命名/设置只做 token 统一，不重排结构。
2. Quick Look/右键菜单保持系统原生，只修明显标签/命中问题。
3. 活动面板继续使用 `FFPaneGlow` 原生阴影；不再改回描边。
4. 详情栏展开高度上限为面板 45%，内容超出滚动。
5. 冲突/删除确认继续使用 NSAlert/sheet；只调整按钮顺序、默认值与危险色。
6. 深色/高对比只做 token 修正，不新增第二套视觉语言。
