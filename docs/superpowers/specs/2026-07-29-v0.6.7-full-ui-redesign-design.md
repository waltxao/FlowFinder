# v0.6.7 全应用 UI 重设计

> **日期：** 2026-07-29
> **版本：** v0.6.7（计划）
> **前置版本：** v0.6.6 (660)
> **状态：** 待用户审阅

---

## 1. 背景

v0.6.6 验收发现 14 个问题，核心根因是"全透明玻璃架构"导致透明度看不清、性能卡顿、设计不统一。用户要求全应用所有窗口重做，从架构层面解决。

## 2. 方向决策

| 决策点 | 选择 |
|--------|------|
| 重设计范围 | 全应用所有窗口重做 |
| 材质架构 | 主窗口侧边栏+边框用亚克力（vibrancy），其他全部实体背景 |
| 操作区背景 | 访达实际色调（日间#F5F5F5/夜间#2D2D2D） |
| 设计方式 | 仿访达原生实现（AppKit 原生组件，不依赖 web skill） |
| 收藏夹 | 命名"个人收藏"，不折叠，直接列出所有文件夹 |
| 标签点击 | 筛选当前活动面板，再次点击取消 |
| 设备栏 | 浮动左下角+实体背景（日间白/夜间黑） |
| 设置页 | 实体背景+分区布局（仿系统偏好设置） |
| 查重页 | 实体背景解决透明度 |
| 详情栏图标 | 空白占位图标，选中后替换 |
| 搜索范围 | 当前目录+子目录本地过滤 |
| 路径栏 | 完全仿访达（固定位置、每段可点击、分隔符弹同级） |
| 分组 | 重新设计仿访达（粘性 header、缩进、计数徽章） |
| 复制/移动反馈 | 底部状态栏进度条（不弹窗） |
| 卡顿 | 排查点击选中/打开+切换目录（缩略图异步/主线程阻塞） |

## 3. 核心架构转变

**从"全透明玻璃架构"转向"亚克力侧边栏 + 实体内容区"架构：**

```
+----------------------------------------------------------+
| 窗口边框（亚克力 vibrancy）                                |
| +----------------+-----------------------+--------------+ |
| | 侧边栏（亚克力） | 操作区（实体#F5F5F5） | 操作区（实体） | |
| | - 个人收藏      | - 工具栏（双行）       | - 同左        | |
| | - 标签          | - 文件列表            |              | |
| | - 底部按钮      | - 详情栏              |              | |
| | (设备浮动左下)  | - 底部状态栏(进度)    |              | |
| +----------------+-----------------------+--------------+ |
+----------------------------------------------------------+
```

- **主窗口侧边栏 + 窗口边框**：NSVisualEffectView `.sidebar` material（亚克力）
- **主窗口操作区**：实体背景，日间 `#F5F5F5`、夜间 `#2D2D2D`
- **所有子窗口**：实体背景，移除 FFGlassView/NSVisualEffectView 透明材质
- **移除 FFGlassView 依赖**：替换为普通 NSView + 实体背景色
- **窗口架构**：保留 titlebarAppearsTransparent（红绿灯浮在侧边栏上方）

## 4. 主窗口重设计

### 4.1 侧边栏（亚克力材质）

- 顶部：应用图标（空白占位风格）+ "FlowFinder" 名称，红绿灯浮在上方
- "个人收藏" section：不折叠，直接列出所有收藏文件夹，彩色真实图标，左对齐
- "标签" section：紧跟个人收藏下方，每行彩色圆点+完整标签名，点击筛选当前面板
- 侧边栏底部：主题切换/设置/工具按钮（紧凑排列）

### 4.2 操作区（实体背景）

- 双面板布局保留（FlowFinder 特性）
- 工具栏（双行）：
  - Row1：后退/前进/上一级/刷新 + 路径栏（完全仿访达）
  - Row2：搜索框 + 排序 + 分组 + 视图切换 + 工具按钮
- 文件列表：列宽自动、药丸列头、分组仿访达、选中强调蓝、缩略图异步
- 详情栏：空白占位图标，选中后替换

### 4.3 路径栏（完全仿访达）

- 固定位置（不再随布局变更）
- 每段路径可点击跳转
- 分隔符可点击弹出同级目录下拉
- 当前位置高亮

### 4.4 分组（重新设计仿访达）

- 粘性 section header（滚动时固定顶部）
- 分组内文件缩进
- section header 显示计数徽章（如"图片 12"）
- 修复 Title 重叠 bug

### 4.5 设备栏（浮动左下角+实体背景）

- 浮动在窗口左下角，实体背景（日间白/夜间黑）
- 展开显示所有设备，不需滚动
- 与侧边栏视觉分离

### 4.6 底部状态栏

- 新增：显示复制/移动进度条（不弹窗）

## 8. 补充：交接文档遗漏项（排查后纳入）

经排查交接文档（HANDOVER.md 8.1 硬约束 / 8.2 用户偏好 / 6.2 待办）与当前代码，发现以下遗漏项纳入 v0.6.7：

### 8.1 A3 - 全局 ErrorBoundary（硬约束第14项，此前完全缺失）

- **现状**：无 `NSSetUncaughtExceptionHandler`，未捕获异常直接 crash
- **修复**：AppDelegate 添加 `NSSetUncaughtExceptionHandler` 捕获未处理异常，弹窗提示错误信息而非崩溃
- **验收**：模拟未捕获异常，应用弹窗提示而非 crash

### 8.2 B4 - 主题恢复三态（用户偏好，v0.6.5 主动移除 .system）

- **现状**：ThemeManager 仅 light/dark 二态，移除了 .system 自动跟随
- **修复**：恢复 AppearanceMode 三态（light/dark/system），.system 跟随 NSApp.effectiveAppearance
- **验收**：设置页有三个选项，选"自动跟随系统"后随系统主题切换

### 8.3 C1 - 工具按钮展开侧边栏底部工具面板（待办第1项，TODO 占位）

- **现状**：`expandBottomToolPanel` 仅 TODO 占位
- **修复**：点击工具按钮展开侧边栏底部工具面板（查重/批量重命名/AI 工具入口）
- **验收**：点击工具按钮，底部展开工具面板

### 8.4 C5 - 大目录性能优化（待办第5项，10万+ 文件）

- **现状**：有 L1+L2 缓存，但无分页/虚拟化/异步批量渲染
- **修复**：文件列表分页加载（首批 500 条立即显示，其余异步追加），避免 10万+ 文件一次性渲染卡顿
- **验收**：打开 10万+ 文件目录，首批快速显示，滚动流畅

### 8.5 标签系统与 macOS 原生标签同步（硬约束，此前仅自有 xattr）

- **现状**：TagBridge 仅读写自有 xattr `com.flowfinder.tags`，未读写 Finder 原生标签（`com.apple.metadata:_kMDItemUserTags`），Finder 中不可见
- **修复**：TagBridge 读写 `_kMDItemUserTags` 实现与 Finder 双向同步
- **验收**：FlowFinder 中添加标签，Finder 中可见；Finder 中添加标签，FlowFinder 中可见

### 8.6 明确废弃的约束（经用户确认）

- **A6 侧边栏区段可折叠**：保持不折叠（用户明确要求），废弃硬约束第7项
- **B1 独立标签列**：保持 4 列+内联药丸，不恢复第5列
- **C3 Intel 通用二进制**：留下一轮

## 9. 不在本设计范围内

- Rust Core / Bridge 层修改（除标签同步涉及的 TagBridge）
- v0.6.6 巡检的 P1/P2 问题（除被本轮覆盖的）
- Intel 通用二进制（C3，留下一轮）

## 10. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 移除 FFGlassView 涉及大量文件 | 分窗口逐步替换，每个窗口独立构建验证 |
| 卡顿根因可能不止缩略图 | 用 systematic-debugging 逐个排查 |
| 路径栏完全重写可能引入新 bug | 参照访达行为逐项实现，每步验证 |
| 分组粘性 header 在 NSTableView 无原生支持 | 自定义滚动监听实现 |
