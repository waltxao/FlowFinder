# v0.8.0 侧边栏收藏模块重设计（参考访达）

> **日期：** 2026-09-02  
> **状态：** P1 已实施（2026-10-17）；P2/P3 待决策（D1/D3/D4 未拍板，D2 已按推荐默认落地）  
> **触发：** ① 收藏导航误杀修复（2026-09-02）暴露的结构性债务；② 用户要求收藏模块对齐访达重设计  
> **范围：** 侧边栏「我的收藏」分区为核心，联动标签区与滚动容器；设备浮层去留为决策点  
> **硬约束：** 分区不折叠（用户明确要求，见 HANDOVER 废弃清单）；简体中文文案；完全克隆访达视觉



---

## 1. 背景

2026-09-02 修复「收藏无法点开」时确认：侧边栏由**三个互相独立的结构**拼成——

| 结构   | 实现                                                                                  | 结构性问题                                                |
| ---- | ----------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 我的收藏 | 独立 `NSOutlineView`，**不套 NSScrollView**，`required` 定高约束（`favoritesHeightConstraint`） | 收藏数量超出定高即溢出/重叠；定高约束是 2026-08-28 沉淀的 AppKit 冲突 bug 温床 |
| 标签   | 自绘 `TagFlowView`（药丸样式），游离在 outline 之外                                               | 无法参与统一键盘导航/拖拽/选中管理                                   |
| 设备   | MainWindowController 内浮动浮层（F10-3 决策）                                                | 与收藏、标签三套交互模型                                         |

访达的侧边栏是**单一 NSOutlineView + 分区 group row**（个人收藏 / iCloud / 位置 / 标签），滚动、排序、键盘、拖拽全是原生能力。当前结构每加一个访达级行为都要在三个结构里各造一份。

## 2. 现状与访达差距

| 能力      | 访达                             | 当前 FlowFinder                                  | 差距等级   |
| ------- | ------------------------------ | ---------------------------------------------- | ------ |
| 容器      | 单一滚动容器，全部分区随内容滚动               | 收藏定高无滚动；标签定高；设备浮层独立                            | **高**  |
| 收藏排序    | 拖拽重排 + 插入位置指示线                 | 仅支持外部拖入**追加**（acceptDrop 只调 addFavorite）       | **高**  |
| 标准位置图标  | 桌面/文稿/下载/应用程序等有**专属彩色图标**      | `NSWorkspace.icon(forFile:)` 通用文件夹图标（F10-4 决策） | 中      |
| 右键菜单    | 从边栏中移除 / 新标签页打开 / 新窗口打开 / 显示简介 | 仅「移除收藏」                                        | 中      |
| 失效收藏    | 外置卷拔出后**灰显保留**，可点击重试           | 无存在性校验，失效项照常显示                                 | 中      |
| 拖文件到收藏项 | = 移动文件到该目录                     | 无此行为（拖到空白区=添加收藏）                               | 低（决策点） |
| 键盘      | ↑↓ 在收藏间移动，Enter 导航             | 无（与 ShortcutCenter 未对接）                        | 低      |
| 标签区     | 色点 + 名称行式                      | 药丸样式（v0.6.6 设计稿 ff-pill-tag）                   | 决策点    |
| 分区折叠    | 支持（hover chevron）              | **不折叠**（用户硬约束，保持）                              | 刻意差异   |

## 3. 方向决策：单一 NSOutlineView 分区模型（核心架构）

**放弃三结构拼接，重建为单一 `NSOutlineView`：**

```
侧边栏 = NSScrollView
  └─ NSOutlineView（无表头，无折叠三角）
       ├─ group row「个人收藏」（不折叠，无 chevron）
       │    └─ SidebarItem.favorite × N
       ├─ group row「标签」
       │    └─ SidebarItem.tag × N
       └─ group row「位置」（决策点 D4，默认保留设备浮层则无此分区）
            └─ SidebarItem.device × N
```

- 分区标题 = `isGroupItem` 行（访达样式：11pt 灰色小字，无高亮，无选中）
- 一个数据源 `SidebarDataSource`（整合现 favorites/tags 数据源），每个分区一个 Section 数组
- 滚动、插入指示线、拖拽、键盘、无障碍全部回归 NSOutlineView 原生路径
- **删除** `favoritesHeightConstraint` / `tagsHeightConstraint` 两条定高约束与 `updateFavoritesHeight`/`updateTagsHeight` 高度计算链（bug 温床整体清除）
- 视觉验证手段：现 `FFSidebarRowView` 自绘高亮与 `FFFNoDisclosureOutlineView` 零矩形方案原样迁移到新 outline

## 4. 重设计详案

### 4.1 容器与布局

- 侧边栏改为 `NSScrollView`（`FFScroller` 细滚动条，overlay，自动隐藏），documentView 承载 outline
- 品牌区（应用图标 + FlowFinder）与底部工具行固定在滚动区**外**（顶部/底部钉住，访达同构：工具栏与底部不动，中间滚动）
- 收藏行高 28pt 维持；分区标题行高 22pt；行间距 0（现方案迁移）
- 空收藏状态：分区标题下显示一行次要文字「拖入文件夹以添加收藏」（访达同款引导）

### 4.2 我的收藏分区

| 行为   | 设计                                                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------------------------ |
| 添加   | ① 外部拖文件夹到分区任意位置（现有）；② 右键菜单「添加收藏到边栏…」弹 NSOpenPanel；③ 菜单栏/快捷键入口对接 ShortcutCenter                                     |
| 排序   | 拖收藏项重排，`NSOutlineView` 原生 `.move` drop + 插入指示线；顺序持久化到现有 `SidebarFavorites` UserDefaults                            |
| 移除   | 右键「从边栏中移除」；拖出侧边栏移除（拖出后松手检测 draggingExited → 移除，访达一致）                                                               |
| 右键菜单 | 从边栏中移除 / 在新标签页中打开（对接窗口 Tab 能力，无则置灰）/ 在新窗口中打开 / 显示简介（复用 FileInfoWindowController）/ 上移 / 下移                          |
| 失效处理 | 数据源维护收藏时**异步存在性校验**（fileExists，后台队列）；失效项图标灰显（`NSWorkspace.icon` 叠加 0.4 透明度）+ 点击时 toast「找不到该文件夹」；**不自动删除**（外置卷重插恢复） |
| 重名   | 添加同名收藏允许（访达允许同名不同路径），显示名冲突时标题带父目录后缀                                                                                |

### 4.3 图标策略（决策点 D1）

| 选项             | 说明                                                                                             | 代价                                         |
| -------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------ |
| A. 维持现状        | `NSWorkspace.icon(forFile:)`，全彩但桌面/文稿等与访达**不同**（访达用专属图标）                                       | 0                                          |
| B. 标准位置映射表（推荐） | 桌面/文稿/下载/应用程序/影片/音乐/图片/主目录 8 个标准位置用**自绘彩色模板图标**（SF Symbol + 分区色着色，20pt），非标准位置回落 NSWorkspace 图标 | 新增 1 个 SidebarIconCatalog（约 80 行）+ 8 张图标资产 |
| C. 系统私有资产      | 直接引用访达侧边栏图标资产名                                                                                 | 依赖私有 API，审核风险，**不推荐**                      |

> 注：B 与用户偏好「彩色真实图标」不冲突——目标正是访达侧边栏的真实观感（访达的桌面/文稿图标本身就是专属彩色图标，而非文件夹本尊图标）。

### 4.4 标签区

- 数据并入统一 outline 的「标签」分区（group row「标签」+ 行式色点项）
- 行式：8pt 色点 + 标签名 + 尾部计数徽章（访达样式）；hover 显示「…」菜单（重命名/删除）
- **决策点 D3**：行式（访达克隆，推荐）vs 保留现药丸样式（v0.6.6 设计稿 ff-pill-tag）
- 点击行为不变：筛选当前活动面板，再点取消（F11-8 现有语义）
- 新增：拖文件到标签上 = 打标签（复用 TagBridge，访达一致）

### 4.5 位置分区（决策点 D4）

- **方案甲（推荐，改动小）**：设备保持浮动浮层（用户现有偏好「设备栏浮动左下角+实体背景」不动），仅把浮层图标从 SF Symbols 换成 `NSWorkspace.icon(forFile: 卷路径)` 真实卷图标
- **方案乙（访达完全体）**：新增「位置」分区并入侧边栏，卷列表 + ⏏ 弹出按钮 + 挂载/卸载通知迁回侧边栏；废弃浮动浮层（F10-3 决策作废）

### 4.6 键盘与无障碍

- ↑↓ 在收藏项间移动（group row 跳过），Enter 导航，⌘↑ 回上一级——经 ShortcutCenter 统一注册
- 无障碍：每行 `accessibilityLabel`（沿用 `FileEntryAccessibility.sidebarLabel`），group row 标记 `AXGroup`

### 4.7 视觉规格（沿用设计令牌）

| 元素    | 规格                                         |
| ----- | ------------------------------------------ |
| 分区标题  | 11pt medium，`secondaryLabelColor`，左缘 12pt  |
| 行     | 高 28pt，图标 20pt，文字 12pt `labelColor`，左缘 6pt |
| 选中高亮  | `FFSidebarRowView` 自绘圆角 6pt（现方案迁移，强调色/失焦灰） |
| 插入指示线 | 系统默认 drop indicator                        |
| 滚动条   | FFScroller overlay                         |

## 5. 与访达的刻意差异（用户偏好优先）

1. **分区不折叠**——访达支持 hover 折叠，硬约束废弃清单明确「用户明确要求不折叠」，group row 无 chevron
2. **失效收藏不静默移除**——访达拖出即删；本项目外置卷场景多（/Volumes/Iris-Data），灰显保留 + 恢复
3. **拖文件到收藏项默认不移动文件**（决策点 D2 可选开）——访达拖到收藏项=移动文件；本项目 v0.7.5 安全取向「目标已存在默认拒绝」，默认仅添加收藏，防误操作

## 7. 实施计划

### P1 收藏分区访达化（本设计核心）

1. `SidebarView` 重建容器：NSScrollView + 单一 outline（迁移 FFSidebarRowView / FFFNoDisclosureOutlineView）
2. 数据源整合 `SidebarDataSource`（favorites 迁移 + group rows），顺序持久化
3. 拖拽重排 + 插入指示线 + 拖出移除；右键菜单全项
4. 失效灰显（异步校验）；空态引导行
5. 删除两条定高约束与高度计算链
6. 回归测试：数据源顺序持久化、失效灰显状态机、group row 选中跳过、拖拽排序意图（纯函数部分）

### P2 标签区并入（D3 拍板后）

标签行式/药丸迁移进统一 outline + 拖文件打标签 + 计数徽章

### P3 设备区（D4 拍板后）

甲：浮层图标真实化；乙：位置分区并入 + ⏏ 对接 `ff_volume_eject`

**涉及文件**：`UI/SidebarView.swift`（主战场，~1800 行中重写约 60%）、`UI/MainWindowController.swift`（通知对接，无守卫逻辑变更）、`Model/SidebarItem.swift`（增加 section 维度）、`Bridge/TagBridge.swift`（P2 打标签）、新增 `UI/SidebarIconCatalog.swift`（D1-B）

**测试**：Swift XCTest 新增数据源/灰显/分组跳过测试（预计 +10）；拖拽意图走可测的纯函数校验层；Rust 侧零改动

## 8. 验收标准

1. 收藏 20+ 项时侧边栏整体滚动，标签/工具行不与收藏重叠（定高约束 bug 类清零）
2. 拖拽可重排收藏并有插入指示线；重启后顺序保持
3. 右键菜单五项功能逐一手测可用
4. 拔掉外置卷后其收藏灰显，重插恢复，不消失
5. 键盘 ↑↓+Enter 可完成收藏导航；VoiceOver 朗读分区与条目
6. 全量测试绿（Rust 200 + Swift ≥108）；活体验收逐项过 §8 清单

## 9. 不在本设计范围内

- 主窗口操作区/文件列表改动（v0.6.7 已定稿）
- 收藏同步 iCloud/多机（数据仍 UserDefaults 单机）
- 设备浮层的布局改动（D4-甲下仅换图标）
- SwiftPM `make run` 修复（独立缺陷，另行处理）

## 10. 风险与缓解

| 风险                                    | 缓解                                                         |
| ------------------------------------- | ---------------------------------------------------------- |
| SidebarView 重写体量大（60%），触碰 97 项既有回归    | 分 P1/P2/P3 三段落地；每段全量测试；SidebarNavigationPosterTests 守住通知契约 |
| 单一 outline 的 group row 选中/拖拽行为与访达细节偏差 | group row `isGroupItem=true` 强制不可选中；拖拽目标校验排除 group row     |
| 定高约束删除后布局回归（设备浮层/工具行锚点变化）             | 底部工具行改锚定 NSScrollView 边缘；8-28 沉淀「瞬态可变约束 defaultHigh」继续执行   |
| 失效校验额外 I/O                            | 后台并发队列 + 启动去抖 500ms，仅对收藏路径 statfs 一次                       |
| 标签行式改动触碰 TagFlowView 既有交互             | P2 独立落地，TagFlowView 保留至验收后删除                               |
