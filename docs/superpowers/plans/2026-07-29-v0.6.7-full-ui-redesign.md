# v0.6.7 全应用 UI 重设计 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 v0.6.6 的 14 个问题 + 5 项交接文档遗漏，全应用从"全透明玻璃架构"转向"亚克力侧边栏+实体内容区"架构。

**Architecture:** 七层分阶段推进：核心架构转变（实体背景）-> 主窗口重设计 -> 路径栏+分组仿访达 -> 子窗口实体化 -> 功能修复 -> 遗漏项补充 -> 视觉打磨。纯 UI 层修改为主，标签同步涉及 TagBridge。

**Tech Stack:** Swift 5.9 + AppKit（NSTableView/NSOutlineView/NSCollectionView/NSStackView/NSSplitView）、NSVisualEffectView（仅侧边栏）、QLThumbnailGenerator、SF Symbols、xattr。Xcode-beta 构建。

```swift
// 捕获未处理异常，弹窗提示而非崩溃
NSSetUncaughtExceptionHandler { exception in
    DispatchQueue.main.async {
        let alert = NSAlert()
        alert.alertStyle = .critical
        alert.messageText = "应用遇到错误"
        alert.informativeText = "错误：\(exception.name.rawValue)\n\n\(exception.reason ?? "未知错误")\n\n请重启应用。"
        alert.addButton(withTitle: "重启")
        alert.addButton(withTitle: "退出")
        let response = alert.runModal()
        if response == .alertFirstButtonReturn {
            NSApp.terminate(nil)
        }
    }
}
```
