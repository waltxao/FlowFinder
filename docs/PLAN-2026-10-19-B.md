## 1. C1：列表元信息合成单列（#11）

### 规格（`docs/PLAN-2026-10-19.md` §3.7 原文）

- 元信息 11pt secondary，右对齐
- 固定两项 `大小 · 修改时间`（如 `1.2 MB · 10月18日 14:32`）
- 面板再窄也不收缩元信息，先省略名称
- 类型列去掉（规格未列入必须项）

### 排序口径（用户已确认）

元信息列头 = 按**修改时间**升降序；按大小 / 按类型排序走工具栏排序菜单。

### 任务

| ID | 文件 | 改动 |
|---|---|---|
| C1-1 | `UI/FFFormat.swift` | 新增 `dateCompact`：当年 `M月d日 HH:mm`，跨年 `yyyy年M月d日` |
| C1-2 | `Model/FileEntry.swift` | 新增 `formattedMetaLine`：`formattedSize` + ` · ` + `dateCompact`（目录 size 为 `--` 时只显示日期） |
| C1-3 | `UI/FileListView.swift` setupColumns | 4 列 → 2 列：`name`（240，min 80）+ `meta`（170，min 160，`sortDescriptorPrototype` key = `modifiedAt`） |
| C1-4 | `UI/FileListView.swift` viewFor | `case "meta"`：11pt、`secondaryLabelColor`、`.right` 对齐、`stringValue = entry.formattedMetaLine`；删 `modifiedAt` / `type` / `size` 三分支 |
| C1-5 | `UI/FileListView.swift` applySortDescriptorsFromViewModel | `.size` / `.type` 时仍映射到 `meta` 列的 key（否则箭头不显示），但列头不呈现大小语义 |
| C1-6 | `UI/FileListView.swift` 列宽策略 | `.sequentialColumnAutoresizingStyle` 下把 `name` 放前面、`meta` 的 `resizingMask` 去掉 `.userResizingMask`，保证窄面板先缩名称 |

### 验收

- 任意面板宽度下不出现横向滚动条
- 元信息始终完整可见（`1.2 MB · 10月18日 14:32` 不被截断）
- 名称在窄面板下尾部省略
- 点元信息列头 → 按修改时间排序，箭头正确

## 2. C2：网格选中两段式（#11）

### 规格（同上）

> 选中：图标后强调色底（缩略图盖在上面，露四周一圈）+ 文件名单独强调色胶囊、文字反白；两块分开

### 现状

`applyVisualState` 把整个 item（112×124）刷成 `FFAccent` 实底 —— 一块到底，与规格不符。

### 任务

| ID | 文件 | 改动 |
|---|---|---|
| C2-1 | `UI/FileGridView.swift` `loadView` | 新增 `iconBackdropView`（插到 `thumbnailImageView` 之前），约束：以缩略图中心为中心、四周各外扩 7pt（最小 34×34） |
| C2-2 | 同上 | 新增 `nameCapsuleView`（位于 `nameLabel` 之下、`thumbnailImageView` 之上），约束跟随 `nameLabel` 四周各外扩 4pt（横向）/ 1pt（纵向），圆角 5 |
| C2-3 | `applyVisualState` | item 自身底色不再上色（保持 `.clear`）；选中时 `iconBackdropView` + `nameCapsuleView` 填 `FFAccent`，取消选中回 `.clear` |
| C2-4 | `prepareForReuse` | 复位两个新视图底色 |
| C2-5 | 无障碍 | 背板与胶囊 `isAccessibilityElement = false`，不干扰 VoiceOver |

### 验收

- 选中：图标能被一圈强调色包住，四周均匀露出
- 文件名是一条独立胶囊，文字反白
- 两块之间有肉眼可见的空隙（不是连成一片）
- 反选 / 复用后无残留色块
- Drop 高亮（8% 底 + 描边）与选中可叠加，互不覆盖

### 保留清单（明确不换，且写注释说明）

系统语义控件不属「图标」范畴，强行替换会破坏系统一致性：

- 窗口红绿灯（`NSWindow.standardWindowButton`）
- `NSOutlineView` 展开三角（`disclosureTriangle`）
- 菜单勾选与箭头（`NSMenuItem.state` 系统绘制）
- 滚动条、`NSTextField` 清除按钮
- 「显示简介」里的系统分区图标（由 `NSWorkspace` 提供）

### 验收

- `grep -rc "NSImage(systemSymbolName"` 剩余数仅出现在保留清单
- `FFIcon.template` / `.image` 调用数从 10 提升到 70+
- 深浅色下模板图自动反色正确（按钮、菜单项）
- 视觉：图标 15pt 工具栏、18pt 列表、13pt 内联，比例与 Lucide 描边粗细一致
