## 1. 用户列出的 12 项

1. 标签页提手与操作区过渡没有圆角内凹。
2. 顶栏没有视觉间隙，红绿灯/按钮/标签顶到上沿；全屏布局异常；希望 Chrome 式宽松。
3. 概率出现操作区内容消失、详情栏悬空的显示 bug（图二）。
4. 顶栏顺序改为：红绿灯 → 侧栏开关 → 面板 1 标签组 → 面板 2 标签组 → 皮肤 → 单双栏。
5. 隐藏侧栏后，面板内面包屑/搜索框被右移。
6. 操作面板宽度调整逻辑不合理，需要重新梳理。
7. 详细信息栏设计突兀，展开后信息混乱。
8. 侧栏工具按钮设计需要重做。
9. 设置页面与相关功能需要重做。
10. 标签管理（新建/管理标签）需要重做。
11. 整体文字、图标偏小，需要重新评估视觉尺寸。
12. 继续在 GitHub 查找图标库，替换/升级现有图标。

## 2. 已确认决策

### 2.1 全局顶栏（对应 2/4/5/11）

- 顶栏是**窗口级全局栏**，跨整个窗口；不再把皮肤/单双栏放在侧栏内部。
- 顺序：红绿灯 → 侧栏开关 → 左面板标签组 → 右面板标签组 → 分隔线 → 皮肤 → 单双栏。
- 密度 C2（用户选定）：
  - 顶栏 44pt；活动标签 38pt；顶部留 6pt 空条；标签底部焊到面板工具栏。
  - 所有元素共用 **22pt 中线**：红绿灯、侧栏开关、标签图标/文字、＋、皮肤/单双栏。
  - 标签文字 13pt、folder 图标 14pt、顶栏图标 16pt（命中 28pt）、关闭 × 10pt。
  - 活动标签与工具栏同色，10pt 内凹肩线；不允许直线硬边。
- 侧栏隐藏：皮肤/单双栏仍在窗口最右侧；面板内面包屑/搜索保持卡片内缩进，不横移。
- 全屏：隐藏红绿灯；侧栏开关/标签组/右侧工具保持 22pt 中线；具体左右边距和侧栏显隐待定。
- 图标大小/线宽/库（第 12 项）待比较后定。

### 2.2 详细信息栏（对应 7）

- **保留浮层**，不改成贴底 footer；浮层仍可调高度。
- 视觉要与面板/工具栏同一套语言：半径 12、1px 边框、柔和阴影、统一字号/间距；不再像“第二张玻璃卡片”。
- 高度：展开范围 **132–300pt**，顶部把手可拖；收起态仍为 54pt（后续可细调）。
- 左侧 **预览单独一列**：默认 132pt，可拖 96–200pt；图标/预览图随列宽缩放。
- 右侧 header：文件名（自动换行，点击编辑，回车保存/Esc 取消）+ 类型/项目摘要。
- 基础字段：类型 / 大小 / 修改日期 / 创建日期 / 位置（自动换行，点击复制）/ 标签（chip 可删可加）/ 说明。
- **去掉**：所有者、权限、磁盘可用等纯技术字段。
- **去掉**：“在 Finder 中打开”、“更多”按钮；所有信息直接列出。
- 类型专属字段（非对应类型隐藏）：
  - 文件夹：项目数
  - 图片：像素尺寸
  - 视频：时长 + 分辨率
  - 音频：时长 + 比特率
  - PDF：页数
  - 应用：版本
  - 压缩包：内含文件数
- 列表底部按浮层高度让位，最后一行不被盖住；浮层仍保持浮动视觉。

### 2.3 图二显示 bug（对应 3）

- 触发面：隐藏/显示侧栏、切单/双栏、拖标签；用户不记得精确步骤。
- 已做：CUA 连续交替侧栏/单双栏压测，AX 表格/行数均正常，未稳定复现；新增
  `FFShellLayoutTests.testSinglePaneActivePaneSwitchFillsSplit` 回归测试（通过）。
- 仍开放：需要日志/新窗口/拖标签路径继续定位；不得用“加延迟/强制重绘”掩盖根因。

### 2.4 面板宽度（对应 6）

- **侧栏宽度独立**：只有拖侧栏缝才改侧栏宽度；窗口缩放、分栏拖拽、单双栏切换**都不写/不挤压侧栏**。
- 窗口整体缩放：两栏**等比缩放**（保持当前左右比例），侧栏宽度不变。
- 分栏拖拽：只改两栏宽度，不触碰侧栏；不改变窗口整体宽度。
- 最小宽度：
  - 窗口最小仍 1060；侧栏 180–280。
  - 两栏**首选最小 400**，允许 **软最小到硬下限 360**；例如窗口 1060 + 侧栏 280 时两栏约 382。
- 单↔双：
  - 双→单：窗口按被隐藏面板的宽度收窄（B 方案），单→双恢复原窗口宽度。
  - 侧栏宽度全程不变；回到双栏恢复此前的左右比例（如 582/582）。
- 待定：分栏把手的命中宽度、双击 50/50、吸附点（实现前确认）。

### 2.5 侧边栏工具入口（对应 8）

- 工具入口从侧栏品牌区移到**全局顶栏最前**：红绿灯 → 工具（wrench）→ 折叠侧栏 → 面板 1 标签组 → 面板 2 标签组 → 分隔线 → 主题 → 单双栏。
- 侧栏品牌区只保留应用名/版本；不再有“工具”药丸。
- 工具按钮 28pt 命中、16pt 线性图标、hover 底色；点击打开现有分组菜单（整理 / 任务 / 系统）。
- 隐藏侧栏时，标签组从工具 + 折叠按钮之后开始；面板内工具栏仍保持 8pt 缩进。
- 工具图标最终形态随第 12 项图标库选型再定。

### 2.6 全局视觉尺寸（对应 11）

- 设置 > 外观提供 **紧凑 / 舒适 / 大** 三档，默认**舒适**；立即生效并持久化。
- 紧凑：正文 12 / 列表行 28 / 工具栏图标 16 / 标签 12 / 侧栏 11 / 详情 11。
- 舒适：正文 13 / 列表行 30 / 工具栏图标 18 / 标签 13 / 侧栏 12.5 / 详情 12。
- 大：正文 14 / 列表行 32 / 工具栏图标 20 / 标签 14 / 侧栏 13.5 / 详情 13。
- 顶栏 C2 的 44pt 高 / 38pt 标签高度不随档位变，仅标签文字与图标随档位缩放。

### 2.7 图标库（对应 12）

- **混合方案**：
  - 系统 chrome（顶栏、工具栏、侧栏、标签、按钮、菜单、状态图标）使用 **SF Symbols**（`NSImage(systemSymbolName:)`，原生光学对齐/权重/明暗）。
  - 文件类型、扩展名、自定义工具入口使用 **Phosphor Icons**（MIT，9000+，6 权重，GitHub）打包为模板资源；默认 regular，次级信息用 light。
- 目标尺寸：17–18pt（舒适档）；三档随 16/18/20 缩放；线宽不再用网页 2px 直接套 16px。
- 不选 Tabler（几何偏硬）、Iconoir（小尺寸偏淡）、Lucide（现状，16px 细）；Remix 因自定义许可证不采用。

### 2.8 设置页视觉（对应 9）

- 保留现有 7 个分区（通用/外观/文件管理/标签管理/网络存储/快捷键/关于）与功能，**只统一视觉**（用户明确痛点）。
- 采用 **A 原生分组卡片**：左侧分区栏 + 右侧分组卡片；卡片 12pt、行 40pt、控件 24–28pt、
  正文 13/说明 11、间距 8/12/16；图标使用 SF Symbols；搜索框 28pt。
- 外观页新增「界面尺寸 紧凑/舒适/大」；保留主题/强调色/列表密度/图标大小/详情预览大小。
- 设置页与主窗共用强调色、字号档位与控件规格；不改信息架构、不删功能。

### 2.9 文件标签（对应 10）

- 标签是**访达原生标签**（`com.apple.metadata:_kMDItemUserTags`），应用内管理定义与颜色，文件 xattr 为真相。
- 改名/改色/删除**同步所有已打标签的文件**；删除二次确认；同名标签可合并；排序只影响侧栏/选择器顺序。
- 唯一新建/管理入口：**设置 > 标签管理**（内嵌管理器）；侧栏“新建 / 管理标签…”和文件标签选择器里的同名入口都跳到这里。
- 侧栏标签区改为**列表行**：颜色点、名称、全局文件计数、勾选态；单选过滤，⌘ 多选 **AND** 交集。
- 给文件打标签：右键/⌥⌘T 打开统一选择器，勾选即批量应用到全部选中项；详情栏标签 chip 使用同一个选择器；支持“清除所有标签”。
- 管理能力：新建、改名、改色、删除、排序、合并；改名/删除/合并前显示影响文件数。
- 新建标签时可选择“仅创建”或“创建并应用到当前选择”；两种都走同一个标签管理器/选择器流程。

### 2.10 隐藏侧栏面包屑/搜索右移（对应 5）

- 已用实机截图确认：隐藏侧栏后左面板工具栏被 `leadingInset=112` 推到右侧，而卡片/list 从 8pt 开始。
- 决定：112pt 只用于窗口顶栏/标签条避让；面板内工具栏保持卡片内 8pt 缩进。
