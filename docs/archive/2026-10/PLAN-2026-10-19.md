## 3. 交互规格

### 3.1 标签数据与删除（#1 / #2）

**原生 xattr 修正**

- 写入：`PropertyListSerialization.data(fromPropertyList: ["名称\n索引", ...], format: .binary)`。
- 读取：优先 plist 数组，每项按换行拆 `名称` + `索引`；失败回退旧文本格式（兼容历史数据）。
- 颜色：`Tag.color` 保留任意 hex；写原生 xattr 时用 `nearestNativeColorIndex(hex)` 取 1–7。
- 侧栏与文件标签统一读 `com.flowfinder.tags` 的 hex；App 内永远同色。
- 启动迁移：把 `SidebarTags` 里的旧 iOS 色保留为 App 色；下次写文件时补上正确的原生索引。

**删除标签**

- 确认框：「将从此设备上所有已记录的 N 个文件中移除，且不可撤销」。
- 路径来源：`TagIndexStore`（SQLite：`tag_name, path`）+ `mdfind "kMDItemUserTags == '名称'"` + 当前目录扫描，三者去重。
- 后台逐个 `removeTagByName`；任务面板显示进度与当前文件，可取消；完成提示「成功 X / 跳过 Y」。
- 索引写入：`TagCountService.count` 批量写、`TagBridge.setTags` 写、目录加载预热写。

### 3.2 标签 UI

- 新建/编辑对话框：名称 + 7 个预设色块 + 「更多…」（macColorPicker 的 `ColorPicker` 视图）+ 取消/保存。
- 侧栏标签右键：编辑标签… / 删除标签。
- 文件右键「标签」：勾选已有标签 + 新建标签… / 管理标签…。
- 侧栏圆点、文件标签药丸、详情栏标签全部用同一个 hex。

### 3.3 侧栏顶部（#7 / #9 / #10）

```
[🔴🟡🟢]  [▤ 隐藏侧栏] [☀/🌙] [▥ 单双窗]
FlowFinder  (渐变 17pt)   [◎ 发现功能 ⌄]
0.7.9 (7901)  10pt
```

- 三图标 24×24、间距 8，从红绿灯右缘 +12 起排；top 按红绿灯中心反算。
- 名称行：渐变文字；右侧「发现功能」药丸（高 22、圆角 11、强调色 12% 底、图标 + 12pt medium + chevron）。侧栏 < 200pt 时药丸收成 24×22 图标态。
- 版本号 10pt secondary，名称下 2pt。
- 齿轮与锤子删除；底部工具行保持撤销状态。
- 「隐藏侧栏」按钮由 `MainWindowController` 持有并浮在最上层：侧栏可见时与另外两个按钮连成一行；隐藏后留在窗口左上角。
- 隐藏：sidebar 从 `mainSplitView` 移除，内容区铺满；恢复按记忆宽度插回 index 0；动画 0.18s；⌘⌥S；状态记忆到 `sidebar_hidden`。
- 进出全屏：重算顶部 top、品牌区、内边距；全屏期间不写 `sidebar_width`。

**发现功能面板**

- `NSPopover`，宽 300，圆角 12，材质 popover。
- 顶部搜索框「搜索功能」28pt；分组：
  - 工具：查重扫描、批量重命名、AI 打标（即将推出）、AI 整理（即将推出）
  - 其他：设置…、关于 FlowFinder
- 行高 44：28×28 圆角图标底 + 标题 13 + 副标题 11 secondary；禁用项灰显、点击无反应。
- ↑↓ 选择、Enter 执行、Esc 关闭。

### 3.4 标签页与面板（#5）

**显示**

- 每个面板一条标签栏，高 32；标签高 26；宽度 100–200 自适应；超出横向滚动。
- 面板标签数 = 1 → 该面板标签栏隐藏，工具栏顶到卡片顶部；≥2 → 显示。
- 两个面板各自独立判断（允许左右顶部高度不同）。

**新建 / 关闭**

- ⌘T / `+` / 右键「在新标签页中打开」：继承当前面板目录，追加到末尾并激活。
- `×` / ⌘W：面板内 ≥2 个标签时关闭当前标签；只剩 1 个时关闭整个窗口。

**拖动**

- 标签内 `mouseDown` 只记起点并选中，不重建视图；`mouseUp` 未拖动才切换；`mouseDragged` 超过 4pt 启动拖拽。
- 组内 drop → 重排；拖到另一面板标签条或面板主体 → 移动（源面板必须 ≥2 个标签）。
- 源面板只剩 1 个标签时禁止拖出（返回禁止光标）。
- 拖到窗口左/右边缘或「分屏投放区」→ 拆成两个面板（仅单面板时）。
  - 单面板开始拖标签时，面板右半区出现虚线投放区；左右边缘同时可投放。
  - 新面板只含被拖走的标签；原面板保留其余标签。
- 双面板时拖到某侧边缘：不拆第三个面板，标签并入**最近那一侧**面板的标签组末尾并激活。

**面板拖动合并**

- 手柄：工具栏空白处（按钮、搜索框、面包屑之外）。
- 拖动整个面板时显示面板快照；另一个面板高亮为投放目标。
- 松手：目标面板保留，被拖面板的标签追加到目标组后面；被拖面板的当前标签成为激活标签；切到单面板模式。
- 任意标签数量都可合并（1+1、2+1、3+2…）。
- 合并后标签栏因 ≥2 个标签而出现。
- 单面板模式下不能再合并。

### 3.5 单面板菜单（#6）

- `FFPaneActionsController` 增加 `isSinglePane` 判定；单窗时隐藏三项并禁用主菜单同名项。
- 「在新标签页中打开」只对单个文件夹显示。

### 3.6 全屏与侧栏宽度（#3）

- `mainSplitView` 的侧栏宽度固定：`splitView(_:shouldAdjustSizeOfSubview:)` 对侧栏返回 `false`，窗口增减宽度全部给操作区。
- 进出全屏：`windowWillEnterFullScreen` / `windowDidExitFullScreen` 重算顶部控制行 top、侧栏内边距、品牌区；`window.invalidateLayout()`。
- 退出全屏恢复进入前宽度；全屏与程序化改宽期间不写 `sidebar_width`。

### 3.7 操作面板（#11）

**图标**

- Lucide 双色：18% 填色 + 2px 描边；文件页 14% 填色 + 2px 描边 + 彩色字形。
- 文件夹按位置分色（见 §1 11b）；普通文件夹 `#5B8DEF`。
- 文件类型：图片 `#A855F7`、视频 `#EF4444`、音频 `#EC4899`、压缩包 `#F59E0B`、代码 `#22C55E`、文档 `#3B82F6`、PDF `#DC2626`、表格 `#16A34A`、演示 `#EA580C`、字体 `#8B5CF6`、其他 `#94A3B8`。
- 缩略图：所有可预览类型走 QuickLook；懒加载 + 缓存；失败回退类型图标；保持原始比例 fit 进 88 框。

**列表**

| 项 | 值 |
|---|---|
| 行高 | 紧凑 26 / 标准 **30** / 宽松 36；标签不再撑高行 |
| 图标 | 18×18；左内边距 10；图标与名称间距 8 |
| 名称 | 13pt，单行，尾部省略 |
| 元信息 | 11pt secondary，右对齐；**固定两项** `大小 · 修改时间`（如 `1.2 MB · 10月18日 14:32`）；面板再窄也不收缩元信息，先省略名称 |
| 标签 | 名称后最多 4 个 6pt 色点 + `+N`；悬停提示完整标签名 |
| 列头 | 24pt；分组头 26pt |
| 选中 | 保持 `FFAccent` 实底 + 白字；悬停 5% label |

**网格**

| 项 | 值 |
|---|---|
| 单元 | 112×124（图标大小设置仍可调 80–200，等比联动） |
| 缩略图 | 最长边 ≈ 单元宽 × 0.78（112 → 88），圆角 8，0.5pt 分隔线描边 |
| 文件夹 | 64×64 双色文件夹图标，居中于 88 框 |
| 名称 | 12pt，两行居中，尾部省略；第二行 10pt secondary 显示大小或修改时间 |
| 间距 | 单元 16 / 行 16，section inset 16 |
| 选中 | 图标后强调色底（缩略图盖在上面，露四周一圈）+ 文件名单独强调色胶囊、文字反白；两块分开 |
| 悬停 | 6% label 底 |
