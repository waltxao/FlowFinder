## 2. 目标结构

```
┌ Sidebar ┬──────────────── Pane A ────────────────┬──────────────── Pane B ────────────────┐
│ 品牌/工具 │ tabs（当前原生标签，保留）              │ tabs（当前原生标签，保留）              │
│ 位置/标签 │ row1: 返回/前进/上级/刷新/面包屑          │ row1: 返回/前进/上级/刷新/面包屑          │
│          │ row2: 搜索 排序 分组 列表/图标 新建 齿轮   │ row2: 搜索 排序 分组 列表/图标 新建 齿轮   │
│          │ list/grid（占满剩余高度）                │ list/grid（占满剩余高度）                │
│          │ details 54pt 浮层（本侧选中/计数/磁盘）   │ details 54pt 浮层（本侧选中/计数/磁盘）   │
└──────────┴─────────────────────────────────────────┴─────────────────────────────────────────┘
                         无全局底栏；任务进度条仅在长任务时展开
```

### 2.1 两行工具栏

- 总高 72pt：row1 32pt + 4pt 间距 + row2 32pt + 上下 4pt。
- row1 保持当前导航 + 面包屑。
- row2 从旧版恢复：搜索、排序、分组、列表/图标、新建文件夹、视图选项齿轮。
- 齿轮固定在 row2 末尾，必须始终可见，不参与“隐藏”。
- 第二行配置为**应用级**，左右两侧一致；默认全部显示。

### 2.2 操作区内详情栏

- 每侧一个，浮在列表/网格底部，左右各 8pt、底部 8pt。
- 收起高度 54pt；点击、拖拽或 ⌘I 展开。
- 无选择：保持旧版收起态，显示本侧目录图标、目录名、项目数、磁盘可用空间；不强制展开。
- 单选：文件图标、名称、类型/大小；展开后显示种类、大小、修改/创建日期、位置、标签、Finder 说明。
- 多选：聚合数量与总大小；展开后不逐项读取媒体。
- 详情栏高度变化通过 `onHeightChanged` 同步列表/网格底部留白。
- 所有元数据由 `MetadataService` 异步读取；不得在主线程同步读 PDF/AV/SMB/目录内容。

### 2.3 `⌘I` 与详情

- `⌘I` 只展开**当前活动面板**的详情栏，不创建新的 popover/window。
- 已展开时再次 `⌘I` 保持展开并刷新当前选择。
- 无选择时保持收起态（旧版行为），`⌘I` 不强制展开空文件卡。
- 退役 `FFDetailsPopoverController`；状态栏的“详情 ⌘I”入口随全局底栏一起移除。

### 2.4 活动面板微光

- 只作用于活动面板；非活动面板无微光、无强调色边。
- 顶部不发光（标签区保持干净）；左/右/下三边可见。
- 底部实、顶部虚：透明度从底部 100% 线性衰减到顶部 0，`fadeStart = 0.42`（从底向上 42% 处开始渐隐）。
- 参数：`blurRadius = 9`、`opacity = 0.50`、圆角 15、内缩 3、顶部 2px 强调色边。
- 颜色：`FFAccent.current`。
- 采用原生 `CALayer` 阴影（`FFPaneGlow`）：无描边、向下偏移，底部/左右更明显、顶部标签区保持干净；参数取 `FFGlowSpec`（blur 9 / opacity .50）。第一版两层渐变描边在真机仍呈硬边，已淘汰。

### 2.5 强调色

- `FFAccent` 是唯一来源；所有带强调语义的元素统一读取它：
  - 活动面板顶部边与三边微光
  - 面包屑当前段
  - 标签下划线
  - 表格/网格选中行
  - 拖拽浮层与插入线
  - 焦点环与模态按钮
- 不再混用 `NSColor.controlAccentColor` 与应用强调色。
- 迁移：首次运行清除旧的 `accent_color`（当前为 `#ff375f`），回退到系统强调色；之后用户可在设置中重新选择。

### 2.6 标签与工具

- 保留当前原生标签样式、单标签常显、拖拽语义；本轮不改标签拖动。
- 保留侧栏品牌区右侧的“工具”药丸与上下文工具浮层；只对齐强调色与间距。

## 3. 视觉规则

- 表面：实体中性色，不使用玻璃/白色描边/整圈粉色发光。
- 分隔：1px hairline；详情栏浮层允许一层轻阴影。
- 字体：SF Pro；标题/正文/说明沿用 `FFVisualTokens`。
- 间距：4/8/12/16/24。
- 活动面板：2px 强调色顶边 + 三边微光；不使用整圈描边。
- 浅色/深色/高对比都必须通过对比度检查；Reduce Motion 下无弹跳/长动画。

## 5. 状态与可访问性

| 状态 | 行为 |
|---|---|
| 无选择 | 详情栏保持收起目录摘要；⌘I 不强制展开 |
| 单选文件/文件夹 | 显示图标/名称/类型/大小；展开异步元数据 |
| 多选 | 聚合数量/总大小；不加载媒体 |
| 详情加载中 | 骨架/“读取中…”；不阻塞列表 |
| 元数据失败 | 保留基础文件名与类型，失败字段显示“无法读取” |
| 第二行全部隐藏 | 齿轮仍可见；row2 保持 32pt，布局不跳动 |
| 活动面板切换 | 微光与 2px 顶边跟随；状态栏已移除，不再有第二个指示 |
| 权限不足 | 沿用 `FFPermissionGate`，不自动重试 |

可访问性：

- 工具栏每个图标按钮有 `accessibilityLabel` 与 tooltip。
- 详情栏展开/收起按钮可键盘到达；`⌘I` 与按钮行为一致。
- 微光是纯视觉，不参与 hitTest；活动面板信息不能只靠颜色。
- 对比度：正文 ≥4.5:1；焦点环 2px。

## 6. 性能门槛

- 选中不触发整表 reload；详情/媒体不在主线程同步读取。
- 500 项首屏 <300ms；滚动 60fps；无主线程 >100ms。
- 微光改为单次原生 layer 阴影（无描边），不恢复 14 层逐层绘制。
- 详情栏高度变化只刷新底部 inset，不重建列表数据。
- 第二行配置变更只切换 `isHidden`/高度，不重建工具栏。

## 9. 显式假设

1. 旧自定义强调色只在升级后清除一次；之后设置可改。
2. 表格选中行也使用应用强调色；系统高亮不再混入（否则红蓝冲突仍在）。
3. 第二行齿轮固定在 row2，永不隐藏；其余五项可隐藏。
4. 详情栏沿用旧版展开内容与重命名/标签动作，但元数据全部异步。
5. 原生标签、单标签常显、工具上下文浮层保留。
6. 任务进度条仍在窗口底部按需展开，但不再是常驻状态栏。
