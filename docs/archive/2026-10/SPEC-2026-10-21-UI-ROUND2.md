## 2. 顶栏几何

| 指标 | 数值 |
|---|---|
| 顶栏高 | 36pt |
| 活动标签高 | 30pt |
| 非活动标签高 | 26pt |
| 顶部空条 | 6pt |
| 内容共用中线（距窗口顶） | 18pt |
| 标签框中心 | 21pt（36 − 6 − 30/2） |
| 标签内容相对框中心上移 | 3pt（21 → 18） |
| 标签左缘距面板左缘 | 26pt（面板圆角 16 + 内凹 10） |
| 顶栏键命中 | 28pt |
| 顶栏图标 | 16pt |
| 标签文字 | 13pt（随界面尺寸档 12/13/14） |
| 标签 folder 图标 | 14pt |
| 红绿灯中心 | 18pt（从系统默认约 14pt 下移） |
| 操作面板上边缘 | 上移 8pt（44 → 36） |

- 顶栏顺序：红绿灯 → 侧栏开关 → 左标签组 → 右标签组 → 分隔线 → 主题 → 单双栏。工具按钮不再出现在顶栏。
- 侧栏隐藏时：红绿灯、侧栏开关常驻，标签组从侧栏开关后开始；面板工具栏保持 8pt 缩进。
- 全屏：隐藏红绿灯，顶栏保持 36pt，左右 16pt，内容仍对齐 18pt 中线。
- 红绿灯只调整垂直位置，水平间距与系统按钮顺序不变；关闭按钮的物理点击必须继续可用。

## 3. 品牌区与工具入口

- 品牌区在侧栏顶部，名称 `FlowFinder` 使用现有渐变字，版本号在名称下方。
- 「工具」胶囊位于品牌区右侧，使用 wrench 图标 + “工具”文字，高度 24pt；点击进入/退出工具页。
- 响应式：
  - 侧栏宽度 ≥ 200pt：胶囊与名称同一行，名称尾部可截断。
  - 侧栏宽度 < 200pt：胶囊移到版本号所在行右侧，名称保持完整，版本号可截断。
- 工具页打开时胶囊呈选中态（强调色底/字）；关闭时恢复普通态。
- 顶栏工具按钮及其 action 删除；工具上下文仍由 `MainWindowController.toolContext()` 提供。

## 4. 工具页

### 4.1 状态矩阵

| 状态 | 侧栏内容 | 胶囊 | 文件区 |
|---|---|---|---|
| 收藏模式（默认） | 收藏 / 位置 / 标签 | 普通 | 可见 |
| 工具页 | 工具页 | 选中 | 可见 |
| 侧栏隐藏 | — | 不可见 | 可见 |

- 进入：点胶囊；退出：点“返回收藏”或再次点胶囊。
- 工具页只替换侧栏内容，不影响活动面板、筛选、滚动位置；返回收藏时恢复原滚动位置（由 AppKit 保留）。
- 工具页打开时选中项变化不改变页面内容；工具可用性在进入页面时按当时上下文计算。

### 4.2 工具清单与分组

| 分组 | 工具 | 可用性 |
|---|---|---|
| 整理 | 重复文件扫描 | 当前路径为空 → “先进入文件夹” |
| 整理 | 批量重命名 | 选中 < 2 → “先选择文件” |
| 任务 | 任务中心 | 始终可用 |
| 系统 | 设置 | 始终可用 |
| 系统 | 关于 | 始终可用 |

- 不显示 AI 自动打标 / AI 智能整理（“即将推出”不进入工具页）。
- 行高 32pt；左侧 16pt 图标，标题 13pt，右侧可用性提示 11pt secondary；不可用行降为 tertiary 且不可点击。
- 点击可用工具：执行 `tool.run(in: context)`，随后返回收藏模式；设置/关于打开对应窗口；任务中心打开任务面板；查重/批量重命名打开现有窗口/弹窗。
- 页面头部只显示“工具”标题和“返回收藏”，不显示路径、选中数量或当前面板。
- 页面高度不足时内容可滚动（使用 NSScrollView 或等效容器），不得被裁剪。

## 5. 操作面板第二行

### 5.1 结构

保留：搜索、排序、分组、列表视图、网格视图、显示设置。
移除：新建文件夹、齿轮（第二行显示）。

### 5.2 显示设置菜单

眼睛按钮（16pt）改名为「显示设置」，菜单包含：

1. 显示项：显示/隐藏隐藏文件、文件标签、文件后缀、系统文件。
2. 第二行显示：搜索、排序、分组、列表 / 图标（复选，持久化到 `toolbar_row2_items`）。
3. 显示列：名称/类型/大小/修改日期/创建日期/标签/说明（现有列菜单）。

- 菜单每次打开时读取最新状态。
- 旧的 `newFolder` 偏好值被忽略；`FFToolbarRow2Item` 不再包含 case `newFolder`。
- 新建文件夹入口保持不变：文件菜单、右键菜单、⇧⌘N。
- 第二行不再出现齿轮按钮；显示设置按钮始终可见。

## 5.5 版本规则（D-09）

| 项 | 规则 |
|---|---|
| 显示形式 | `A.B.C-yymmddxx`，例 `0.8.0-26102201 Beta`（侧栏版本行、关于页、单实例提示同一来源） |
| `CFBundleShortVersionString` | 保持纯 `A.B.C`（`0.8.0`）；系统要求三段数字，不带后缀 |
| `CFBundleVersion` | 存 `yymmddxx`（8 位数字，同日序号 01 起，天然单调递增） |
| 递增时机 | `make build` / `make release` / `make beta` 每次执行前置递增；`make bump-version` 可单独执行 |
| 同日多次构建 | 读到当天前缀则序号 +1；读到非当天值（含历史 `8001`）重置为 `01` |
| 唯一真源 | 仍是 Xcode 工程（`scripts/lib-version.sh` 读取，脚本与 UI 都不硬编码） |
