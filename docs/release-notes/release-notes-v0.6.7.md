# FlowFinder Native v0.6.7 (670)

**发布日期：** 2026-07-29
**版本：** 0.6.7 (670)
**分支：** main

---

## 本次发布概述

v0.6.7 是一次全应用 UI 重设计版本，核心架构从"全透明玻璃"转向"亚克力侧边栏 + 实体内容区"。修复 v0.6.6 验收发现的 14 个问题 + 5 项交接文档遗漏。

## 核心架构转变

- **侧边栏 + 窗口边框**：保留访达风格亚克力（vibrancy）材质
- **操作区（左右面板）**：实体背景（日间 #F5F5F5 / 夜间 #2D2D2D），清晰可读
- **所有子窗口**（设置/查重/搜索/关于/对话框等）：实体背景，移除 FFGlassView 透明材质
- **性能改善**：减少玻璃材质实时模糊计算，缩略图异步加载

## 14 个问题修复

### 第一层：核心架构转变

- **[F11-1]** 操作区实体背景（日间 #F5F5F5 / 夜间 #2D2D2D），侧边栏保留亚克力
- **[F11-2]** 子窗口全部实体背景 + 移除 FFGlassView（设置/查重/搜索/关于/对话框等 8 文件）
- **[F11-3]** 主题恢复三态（浅色/深色/自动跟随系统）+ 全局 ErrorBoundary（捕获未处理异常弹窗）

### 第二层：主窗口重设计

- **[F11-4]** 路径栏完全仿访达重写：固定位置、每段可点击跳转、分隔符弹同级下拉、当前位置高亮
- **[F11-5]** 分组重新设计仿访达：粘性 section header（滚动固定顶部）、计数徽章、分组内缩进、修复 Title 重叠 bug（根因：rowView 层+cellView 层双重绘制）
- **[F11-6]** 详情栏空白占位图标 + 设备栏实体背景

### 第三层：功能修复

- **[F11-7]** 卡顿修复：NSWorkspace.icon 缓存、磁盘缓存异步、缩略图完全异步加载
- **[F11-8]** 搜索修复（子目录递归搜索 + 基于 allFiles 非已过滤子集）+ 标签点击筛选当前面板
- **[F11-9]** 复制/移动底部进度栏（动态高度展开 + 文件名/百分比 + 完成淡出收起）

### 第四层：遗漏项补充

- **[F11-10]** 标签系统与 macOS 原生标签同步（读写 \_kMDItemUserTags，Finder 双向可见）
- **[F11-11]** 工具面板展开（查重/批量重命名/AI 入口）+ 大目录分页性能（首批 500 异步追加）

## 明确废弃的约束

- 侧边栏区段可折叠：保持不折叠（用户确认，废弃硬约束第7项）
- 独立标签列：保持 4 列 + 内联药丸
- Intel 通用二进制：留下一轮

## 系统要求

- macOS 13.0+（Apple Silicon 或 Intel）
- 建议 macOS 14.0+ 以获得完整视觉体验
