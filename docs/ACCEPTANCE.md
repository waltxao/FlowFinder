# FlowFinder 验收标准

> **版本：** 1.0
> **日期：** 2026-10-17
> **性质：** 「什么算做对了」的唯一判定依据。规格本体见 `docs/DESIGN-SPEC.md`
> **原则：** 每条都必须能给出「通过 / 不通过」的结论。凡是只能靠感觉判断的，一律改写成本文件里的可执行条件。

---

## 1. 视觉验收

### 1.1 对照条件

截图必须固定以下变量，否则无法比对：

| 项 | 固定值 |
|---|---|
| 窗口尺寸 | 1440 × 900 |
| 窗口位置 | 屏幕左上角对齐 |
| 外观 | 浅色与深色各一张 |
| 列表密度 | 标准档 |
| 内容 | 同一个含 30+ 文件的目录 |
| 缩放 | Retina 原生（不缩放截图） |

### 1.2 五类判定

| 类别 | 判定方式 | 通过标准 |
|---|---|---|
| **结构** | 量像素 / 看约束 | 侧栏 200pt；工具栏 72pt（4+32+4+32）；详情栏收起 54pt；面板 1px 发丝线、无可见分割线 |
| **字号** | 对照 §1.3 表 | 每类文本落在指定档位，误差 0 |
| **材质** | 遮住窗口后方内容观察 | 侧栏有 vibrancy 透出；操作区完全实心，不透明度 100% |
| **选中态** | 获焦 / 失焦各截一张 | 获焦为系统强调色 + 白字；失焦为灰底 + 主文字色；不得出现蓝色描边 |
| **间距** | 量像素 | 详情栏浮层四周 8pt；分组缩进 16pt；列表左右内边距 8pt |

### 1.3 字号对照表

| 位置 | 档位 | 字号 |
|---|---|---|
| 列表文件名、网格文件名、侧栏条目、按钮 | base | 13 regular |
| 详情栏文件名、弹窗标题 | lg | 15 semibold |
| 列头、分组标题 | captionEmphasis | 11 semibold |
| 分区标题 | captionEmphasis | 11 semibold |
| 路径、次要说明 | caption | 12 regular |
| 详情栏字段标签 | xs | 10 regular |
| 徽标、计数 | xs | 10 regular |
| 空态主标题、引导页标题 | xl | 17 semibold |

### 1.4 不纳入判定的项

以下允许存在差异，**不作为不通过的理由**：

- 文件类型图标的绘制细节（用系统图标即可）
- 动画时长与缓动曲线
- 字体渲染的次像素差异
- 访达特有的、本产品未实现的功能入口（如标签页、共享菜单）

## 2. 功能验收

每条给一个可执行的通过条件。「通过条件」必须是能动手验证的动作，不是形容词。

### 2.1 窗口与布局

| ID | 需求 | 通过条件 |
|---|---|---|
| L-01 | 双栏布局 | 拖动中间分隔条，两侧比例变化；重启后比例保持 |
| L-02 | 无系统 title 栏 | 窗口顶部无标题文字；红绿灯浮在侧栏上方，可正常点击 |
| L-03 | 侧栏亚克力 | 把窗口拖到有内容的背景上，侧栏能透出背景模糊；操作区不透 |
| L-05 | 无可见分割线 | 侧栏与操作区之间只有 1px 发丝线，无 2px 以上间隙或色带 |
| L-06 | 拖动调宽反馈 | 拖分隔条时，鼠标位置出现渐变亮线，**无蓝色边框** |
| L-09 | 底部进度栏 | 复制 1GB 以上文件时展开，显示百分比与当前文件名；完成后收起 |
| L-10 | 设备浮层 | 固定左下角，插拔 U 盘后列表即时更新 |

### 2.2 工具栏与导航

| ID | 需求 | 通过条件 |
|---|---|---|
| T-01 | 双行工具栏 | 工具栏总高 72pt；Row1 与 Row2 各 32pt |
| T-03 | 面包屑在 Row1 | 后退 / 前进 / 上一级 / 刷新 / 面包屑同一行 |
| T-04 | 刷新位置 | 刷新按钮紧贴面包屑左侧，中间无空隙 |
| T-05 | 面包屑每段可点击 | 点任一段跳到该级；点 `>` 弹出同级目录菜单 |
| T-06 | 面包屑溢出 | 路径长到放不下时，右侧仍显示当前目录名，左侧出现省略号；点省略号能看到被隐藏的段 |
| T-09 | 视图切换 | 点列表/网格按钮，视图即时切换；重启后保持 |

### 2.3 文件列表与网格

| ID | 需求 | 通过条件 |
|---|---|---|
| V-01 | 四列 | 名称 / 修改日期 / 类型 / 大小四列齐全；窗口拉宽时四列按比例变宽，无横向滚动条 |
| V-02 | 药丸列头 | 列头为圆角背景；按住拖动可调整列顺序 |
| V-03 | 列头排序 | 点同一列头，升序↔降序切换，箭头方向随之变化 |
| V-04 | 分组 | 选「按种类」后出现分组标题行；滚动时标题吸顶；标题右侧有计数 |
| V-05 | 行高 | 标准档无标签行 26pt、有标签行 48pt；切到紧凑档变 22 / 42 |
| V-06 | 选中态 | 点击文件行，获焦时蓝底白字；点另一栏后变灰底 |
| V-08 | 隐藏文件 | ⌘⇧. 切换后隐藏文件出现，文字为灰色 |
| V-10 | 大目录 | 打开含 5000 个文件的目录，首屏立即出现，其余异步补齐，滚动不卡 |

### 2.4 详情栏

| ID | 需求 | 通过条件 |
|---|---|---|
| D-01 | 浮层形态 | 详情栏四角为圆角，四周能看到底层列表透出 8pt |
| D-03 | 两档高度 | 点击展开，高度 210pt；再点收起，高度 54pt |
| D-04 | 拖拽调高 | 拖详情栏上边缘可改高度；拖右栏详情栏，左栏同步变化 |
| D-06 | 流动填充 | 展开后字段装不下时，多出的字段出现在第二列；两列都满则不显示，不出现滚动条 |
| D-07 | 状态栏 | 底部显示「N 个项目」与磁盘可用空间；选中文件时数字变化 |
| D-11 | 多选汇总 | 选 3 个文件，详情栏显示数量 3 与总大小 |
| D-13 | 列表最后一行 | 滚动到底，最后一行完整可见，不被详情栏遮住 |

### 2.5 文件操作

| ID | 需求 | 通过条件 |
|---|---|---|
| O-01 | 基本操作 | 复制 / 剪切 / 粘贴 / 重命名 / 删除 / 新建文件夹各执行一次，结果正确 |
| O-02 | 跨面板 | 左栏选文件按 ⌘⇧C，文件出现在右栏当前目录 |
| O-03 | 在另一侧打开 | 右键文件夹选「在另一侧打开」，右栏跳到该文件夹 |
| O-04 | 拖拽语义 | 同盘拖动 = 移动；按住 ⌘ 拖动 = 复制；跨盘拖动 = 复制 |
| O-05 | 冲突三选 | 复制同名文件，弹窗有替换 / 保留两者 / 跳过；选「保留两者」生成「副本」 |
| O-06 | 撤销 | 删除后 ⌘Z，文件回到原位；⌘⇧Z 再次删除 |
| O-07 | 废纸篓 | 删除的文件出现在废纸篓，可从废纸篓还原 |

### 2.6 侧边栏

| ID | 需求 | 通过条件 |
|---|---|---|
| S-03 | 收藏不折叠 | 「个人收藏」标题无展开箭头，收藏项始终全部可见 |
| S-05 | 彩色图标 | 收藏的文件夹显示系统彩色图标，不是统一蓝色模板 |
| S-06 | 拖拽重排 | 拖动一个收藏到另一个位置，松手后顺序变化；重启后保持 |
| S-08 | 失效收藏 | 删除一个被收藏的文件夹，该行变灰但仍存在，悬停显示原因 |
| S-11 | 标签筛选 | 点标签，当前活动面板只显示带该标签的文件；再点恢复全部 |
| S-13 | SMB 挂载 | ⌘K 输入 smb 地址可挂载，挂载后出现在设备浮层 |

### 2.7 搜索 / 预览 / 标签

| ID | 需求 | 通过条件 |
|---|---|---|
| F-01 | 面板内搜索 | 输入关键词，300ms 内列表过滤；清空后恢复 |
| F-04 | QuickLook | 选中文件按空格，弹出预览；按方向键切换；Esc 关闭 |
| F-05 | 标签互通 | 在 FlowFinder 给文件打标签，打开访达「显示简介」能看到同一标签 |
| F-06 | 查重 | 选一个目录扫描，结果按重复组分列；每组至少保留一个被勾选 |
| F-07 | 批量重命名 | 选 3 个文件，用「添加序号」规则重命名，结果符合预览 |
| F-09 | 自动打标签 | 菜单文案为「按类型自动打标签」，不出现「AI」字样 |

### 2.8 键盘与无障碍

| ID | 需求 | 通过条件 |
|---|---|---|
| K-01 | Tab 流转 | 连续按 Tab，焦点按 侧栏→左栏→右栏 顺序移动，不跳出窗口 |
| K-02 | 快捷键生效 | 在设置里改一个快捷键，返回主窗口立即按新键生效 |
| K-03 | 文本编辑不劫持 | 重命名输入框中 ⌘C/⌘V/⌘A 执行文本操作，不触发文件操作 |
| K-04 | ⌘F 聚焦 | 按 ⌘F，光标进入当前活动面板的搜索框 |
| K-05 | VoiceOver | 开启 VoiceOver，侧栏条目朗读出名称与类型 |

## 4. 非功能验收

| 项 | 指标 | 验证方式 |
|---|---|---|
| 冷启动 | 进程出现 < 1s，窗口可交互 < 2s | 秒表，重复 3 次取均值 |

| 大目录滚动 | 10,000 项 ≥ 55fps | Instruments |
| 常驻内存 | < 250MB（1 万项目录） | Activity Monitor |
| 约束冲突 | 0 条 | 控制台搜 `Unable to simultaneously satisfy` |
| 崩溃 | 5 条旅程各跑 3 遍，0 崩溃 | 手工 + 日志 |
| 测试 | Rust 200 / Swift 115+ 全绿 | `make test` |
