# FlowFinder 验收标准

> **版本：** 1.1
> **日期：** 2026-10-22（按当前实现校正数值）
> **性质：** 「什么算做对了」的唯一判定依据。规格本体见 `docs/DESIGN-SPEC.md`
> **原则：** 每条都必须能给出「通过 / 不通过」的结论。凡是只能靠感觉判断的，一律改写成本文件里的可执行条件。

---

## 1. 视觉验收

### 1.1 对照条件

| 项 | 固定值 |
|---|---|
| 窗口尺寸 | 1440 × 900 |
| 窗口位置 | 屏幕左上角对齐 |
| 外观 | 浅色与深色各一张 |
| 列表密度 | 标准档 |
| 内容 | 同一个含 30+ 文件的目录 |
| 缩放 | Retina 原生（不缩放截图） |

### 1.2 结构判定

| 项 | 当前值 |
|---|---|
| 侧栏宽度 | 默认 220pt，可拖 180–280pt，重启保持 |
| 操作面板工具栏 | 72pt（4 + 32 + 4 + 32） |
| 全局顶栏 | 36pt；活动标签 30 / 非活动 26 / 顶部空条 6 |
| 顶栏共用中线 | 距窗口顶 18pt（红绿灯、侧栏开关、标签内容、右侧按钮） |
| 标签内容偏移 | 相对标签框中心上移 3pt |
| 详情栏 | 收起 54pt；展开 132–300pt；预览列 96–200pt |
| 圆角 | 控件 6 / 卡片 8 / 详情 12 / 面板 12 / 窗口 12 |
| 面板边缘 | 活动面板 2pt 强调色边；列表与工具栏之间 1px 发丝线 |

### 1.3 字号对照

| 位置 | 字号 |
|---|---|
| 列表文件名、网格文件名、侧栏条目、按钮 | 随界面尺寸档 12 / 13 / 14（默认 13） |
| 详情栏文件名、弹窗标题 | 15 semibold |
| 列头、分组标题、分区标题 | 11 semibold（设置分区标题 13 semibold） |
| 路径、次要说明、工具行提示 | 11–12 |
| 详情栏字段标签、徽标、计数 | 10–11 |
| 空态主标题 | 17 semibold |

### 1.4 不纳入判定

- 文件类型图标绘制细节
- 动画时长与缓动曲线
- 字体渲染次像素差异
- 访达特有、本产品未实现的入口

### 2.7 搜索 / 预览 / 标签 / 设置

| ID | 需求 | 通过条件 |
|---|---|---|
